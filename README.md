# Linguosofia — sito per il server

## Scarica il pacchetto

**[Scarica linguosofia-sito.zip](https://github.com/luke-garrison-dev/linguosofia-sito/raw/main/linguosofia-sito.zip)**

1. Clicca il link: il file si scarica sul computer.
2. Decomprimilo (Windows: tasto destro → Estrai tutto; Mac: doppio clic).
3. Carica **tutto il contenuto** della cartella `linguosofia-sito` nella cartella pubblica del hosting (`public_html` o `www`).
